# Verification evidence

These are recorded test outputs and terminal captures, not inputs to the build or runtime. Start with [the latest TUI crash repair](tui-crash-fix/README.md) for the current source verification. [Build reorganization](build-reorg/README.md) records the preceding clean build and its one observed crash.

The remaining directories preserve earlier phase evidence: `g5-rc/`, `usability-repair/`, `review-remediation/`, `component-rewrite/`, and `visual-polish/`. Their logs and screenshots are historical and may describe source or binary versions that no longer exist. The corresponding phase documents in `docs/` name their exact evidence and limits. Do not use an older pass result as a claim about the current working tree or as a substitute for user G5 acceptance.
