## TUI / Profile

- `xrm tui` 无参数即可进入；--profile只是可选捷径。
- Profile页支持可读名称的创建/选择/复制/重命名/删除；UUID只作为内部稳定标识，不要求用户抄写。
- 无Profile时仍能管理全局订阅；提供创建默认本地配置方案的简单引导，不自动接管系统网络。
- 单Profile自动选中，多Profile可见切换；浏览切换不自动重启。当前编辑方案与实际运行方案不同必须显示。
- disabled是“不参与输出”，不是“无法打开”。没有源文件时展示未配置状态与创建入口；已有源照常编辑。不得为避免崩溃自动启用所有模块。
- 保留并完善原生模块页的说明与文件位置。复杂JSON优先提供显眼的外部编辑；常用表单仍可用。内嵌编辑至少保证正常多行、粘贴、Unicode和保存/取消，不重写IDE。
- Ctrl-S等终端交互必须在普通真实终端生效，不能只修改PTY fixture让测试变绿。
